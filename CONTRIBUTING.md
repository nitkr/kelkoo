# Contributing to Kelkoo

This is a personal fork. If you open a PR:

1. Keep display name **Kelkoo** and package id `app.kelkoo.music`.
2. Do not reintroduce Echo Music branding, screenshots, or marketing links.
3. Do not commit plans, verify docs, or a `.gitignore` (use `.git/info/exclude` locally).
4. Prefer small, tested changes. Run `./gradlew assembleUniversalFossDebug` when you can.

Upstream heritage: [Echo Music](https://github.com/EchoMusicApp/Echo-Music) (GPL-3.0).
